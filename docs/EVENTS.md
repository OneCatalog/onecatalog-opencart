# События расширения (§8) — точки расширения для сайтового слоя

Ядро публикует события OpenCart, через которые сайт дополняет логику **без форка**
расширения (граница «универсальное ↔ проектное», §8 стандарта). Поля payload, не
входящие в таблицу маппинга (текстура, площадь упаковки, рейтинг, раскладка цен по
регионам / остатков по складам и т.п.), сайт дозаполняет в обработчике события.

## Доступные события

| Событие | Когда | Аргументы (один массив) |
|---|---|---|
| `onecatalog.product.imported` | после импорта одного товара | `{ product_id, public_id, status('created'|'updated'), payload }` |
| `onecatalog.pricestock.updated` | после записи цены/остатка (B2B, §13.7) | `{ product_id, record, offers }` — `offers` это СЫРЫЕ офферы фида (все регионы/склады) |

`record` (B2B) = `{ regular, sale, purchasing, manage, qty, stock_raw, status, sig }`.

## Как подписаться

Зарегистрируйте обработчик через модель событий OpenCart (например, в `install()`
своего модуля):

```php
$this->load->model('setting/event');
$this->model_setting_event->addEvent(
    'mysite_oc_pricestock',                 // код
    'onecatalog.pricestock.updated',         // триггер
    'extension/module/mysite/onPriceStock'   // ваш маршрут-обработчик
);
```

Обработчик в контроллере/модели получает аргументы события:

```php
public function onPriceStock($route, array $args) {
    $data = $args[0];
    $productId = (int) $data['product_id'];
    foreach ($data['offers'] as $offer) {
        // разложить цены по регионам / остатки по складам в свои поля/таблицы
    }
}
```

## Change-detection и события (важно §13.4)

Синхронизация цен/остатков пишет товар **только если изменилась сигнатура** результата
(цена/скидка/остаток/статус). Если в обработчике вы раскладываете ВЕСЬ payload (все
регионы/склады), изменения в неосновных регионах/складах **не вызовут** обновление —
scan-and-diff их пропустит, и событие не сработает. В этом случае расширьте сигнатуру
(в будущих версиях — через фильтр сигнатуры) или примите, что обновление триггерится
изменением основного региона/итогового остатка.
