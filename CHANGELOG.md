# История изменений — OneCatalog Import (OpenCart)

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
нумерация версий — по [семантическому версионированию](https://semver.org/lang/ru/).

Соответствие стандарту интеграции: **v1.2** (см.
[onecatalog-standard](https://github.com/OneCatalog/onecatalog-standard)).
Целевая платформа: **OpenCart 3.0.3.x**.

## [Не выпущено] — бэклог

### Реализовано на `dev` — пикер + AJAX-степпер импорта + UX (версия 0.4.0)
- **Пикер** (`picker-loader.js`, §2.4 v1.2): iframe виджета; `parentOrigin =
  window.location.origin` (на клиенте); доверие по `event.source === iframe`; разбор
  JSON-строки `event.data`; своя кнопка × + Esc. Импорт по `productPublicIds`.
- **AJAX-степпер** (`admin-import.js`, §6 v1.2): порции по «шагу импорта» →
  `extension/module/onecatalog/importBatch`; лоадер (спиннер+бар), сводка
  (создано/обновлено/ошибок), **отмена** между порциями, **persist** последнего
  результата (`localStorage`); пикер и поле ввода независимы, повторный запуск
  заблокирован.
- **Контроллер**: страница «Импорт» (`importPage`) + AJAX `importBatch` (права +
  токен; импорт порции через `ProductImporter`, запись в `onecatalog_log`). Кнопка
  «Импорт» на странице настроек; меню OCMOD — родитель «OneCatalog» с детьми
  Импорт/Настройки. RU/EN-локализация (включая JS-строки).
- ✅ После этого инкремента импорт **кликается end-to-end** в админке.


### Реализовано на `dev` — медиа: обложка/галерея, качество, дедуп (версия 0.3.0)
- **`OneCatalogMedia`** (`system/library`, чистые хелперы): выбор размера (с токеном →
  max), контент-ключ дедупа `sha1(path#size)` из base64-префикса `media_files`
  (стабилен между токенами/подписями), MIME→расширение. Покрыто офлайн-тестом
  (`tests/media-test.php`, 11 проверок).
- **`ModelExtensionOnecatalogMedia`**: обложка → `product.image`, галерея →
  `product_image`; URL без расширения → ручное скачивание + MIME по содержимому (§2.3);
  **дедуп** по контент-ключу (таблица `onecatalog_media`) — один файл качается один раз;
  **трекинг качества** (`min/middle/max`): лучший размер перекачиваем, общие файлы не
  удаляем (§5.3). Рекорды качества/галереи — в `onecatalog_meta` (не поля товара).
- Медиа подключено в `ProductImporter` после категорий/характеристик.


### Реализовано на `dev` — ядро импорта одного товара (версия 0.2.0)
- **`OneCatalogApi`** (`system/library`) — клиент Wiki API: `{base}/products/{public_id}/`,
  заголовок `X-API-Key`, параметр `lang`, ответ `{success,data}`; `getBinary` для медиа.
- **`OneCatalogUnits`** — конвертер г→класс веса / мм→класс длины магазина (§5.6),
  покрыт офлайн-тестом (`tests/units-test.php`, 11 проверок).
- **`ModelExtensionOnecatalogImport`** — импорт одного товара прямым SQL по нативным
  таблицам: идемпотентность по `onecatalog_map` (не по model/sku, §5.1); `model←article`;
  название/описание на все языки магазина; категории-дерево find-or-create (+ closure
  `category_path`); характеристики → нативные `attribute` (группа «OneCatalog», find-by-
  name, boolean→Yes/No, §5.4); габариты через Units. **Цена и статус — только при
  создании** (§5.6), при переимпорте не затираются; цена не синтезируется (`0`).


### Реализовано на `dev` — каркас расширения (версия 0.1.0)
- **Структура MVC-L** OpenCart 3.0.3.x: контроллер/модель/шаблон/языки
  (`extension/module/onecatalog`), упаковка под `.ocmod.zip` (`install.xml` + `upload/`).
- **Установка**: служебные таблицы (§5.1 — служебное вне формы товара) —
  `onecatalog_map` (идемпотентность public_id ↔ product_id), `onecatalog_meta`
  (сигнатуры/коды), `onecatalog_media` (дедуп по контент-ключу), `onecatalog_queue`,
  `onecatalog_log`. При удалении карта НЕ стирается (защита от задвоения).
- **Страница настроек** (хранение через `setting/setting`): база/токен Wiki API, язык,
  шаг импорта (≥10), статус новых товаров, origin пикера. RU/EN-локализация.
- **OCMOD-меню** «OneCatalog» в админке (best-effort, `error="skip"`; фолбэк —
  «Расширения → Модули»). Права маршрута выдаются группе при установке.
- ⚠️ Следующий инкремент 0.2.0 — ядро импорта одного товара (§5).
